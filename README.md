# Планёрка

Личный центр управления жизнью. Работает полностью локально: Next.js (React) на фронтенде и бэкенде, SQLite как база данных (встроенный `node:sqlite`, без сторонних зависимостей для БД). Данные никуда не отправляются, кроме голосового чата — там реплики уходят в Claude API (Anthropic) для ответа и сбора плана.

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000) (если порт занят, Next.js сам подберёт следующий свободный — смотри, что написано в терминале). Изменения в коде подхватываются на лету.

Для «боевого» запуска (сборка + старт одной командой):

```bash
npm start
```

### Голосовая планёрка — нужен API-ключ

Раздел «Голосовая планёрка» использует Claude API для диалога и сбора плана дня. Скопируй `.env.local.example` в `.env.local` и вставь свой ключ с [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys):

```
ANTHROPIC_API_KEY=sk-ant-...
```

Без ключа остальные разделы (профиль, задачи, аналитика, здоровье) работают как обычно.

## Что уже готово

- **00 · Голосовая планёрка** — утренний голосовой диалог с Claude: распознавание речи локально в браузере (Whisper через `@huggingface/transformers`, с откатом на встроенное распознавание браузера), ответы озвучиваются через синтез речи браузера. По итогам разговора собирается список задач на день.
- **01 · Личный кабинет** — ФИО, дата рождения (возраст считается сам), пол, город, рост/вес (ИМТ и его категория считаются на лету), телефон, email, профессия, группа крови, аллергии, «о себе».
- **02 · Задачи и цели** — быстрое добавление задач (категория, приоритет, период день/неделя/месяц/год, срок), отметка выполнения чекбоксом, фильтр по периоду, просроченные подсвечиваются.
- **03 · Аналитика** — дашборд по задачам: всего/выполнено/активно/% выполнения/серия дней/просрочено, график выполненных задач за 14 дней, разбивка по категориям (донат) и по приоритету (столбцы).
- **04 · Здоровье и тренировки** — программа тренировок (недельный сплит на диапазон дат), календарь по месяцам, план и факт по каждому подходу (повторы × вес), учёт веса тела по дням.
  - **Автопрогрессия весов** — при открытии ещё не выполненного упражнения приложение само предлагает вес на подходы: если в прошлый раз выполнены все повторы — +2.5 кг, если нет — тот же вес, с объяснением почему.
- **Прогресс** (`/health/progress`) — графики рабочего веса и объёма по каждому упражнению (по всей истории, не только за месяц) + график веса тела.
- **Библиотека упражнений** (`/health/exercises`) — 60+ упражнений с техникой выполнения и анатомической картой нагрузки (SVG-силуэт спереди и сзади). Тело разобрано на **37 мышечных пучков** (грудь: верх/середина/низ; трицепс: 3 головки; квадрицепс: 3 головки; трапеция: 3 отдела и т.д.). Клик по упражнению подсвечивает мышцы по трём уровням: 🔴 целевая, 🟠 помогает заметно, 🟡 работает фоново как стабилизатор.

Разделы «Финансы», «Заметки» показаны в меню как «скоро» — под них уже подготовлены таблицы в базе данных.

## Занести задачи из текстового отчёта

Можно прислать список дел текстом прямо в чат с Claude Code — он разберёт и занесёт задачи в базу через `scripts/add-tasks.mjs`, минуя интерфейс:

```bash
node scripts/add-tasks.mjs '[{"title":"...", "category":"work", "priority":"medium", "period":"day", "due_date":"2026-08-07"}]'
```

## Структура

```
src/
  app/
    voice/          — страница голосовой планёрки
    profile/        — страница Личного кабинета
    tasks/          — страница Задач
    analytics/      — страница Аналитики
    health/         — страница Здоровья и тренировок
    layout.tsx      — общий каркас (сайдбар + шапка)
    globals.css     — дизайн-токены и тема
  components/       — UI-компоненты
  workers/
    whisper-worker.ts — локальное распознавание речи (Web Worker)
  lib/
    db.ts             — подключение к SQLite и схема таблиц
    queries.ts         — чтение данных (для серверных компонентов)
    actions.ts          — server actions: профиль, задачи
    healthActions.ts     — server actions: программы тренировок, факт, вес тела
    voiceActions.ts       — server actions: диалог и сбор плана через Claude API
    analytics.ts           — расчёт статистики для дашборда задач
    workoutProgress.ts      — агрегация логов тренировок в серии для графиков
    progression.ts           — расчёт рекомендованного веса на следующую тренировку
    audio.ts                  — запись голоса → PCM 16кГц для Whisper
scripts/
  add-tasks.mjs     — служебный скрипт: добавляет задачи в базу напрямую
data/
  planerka.db       — база данных SQLite (создаётся автоматически при первом запуске)
```
